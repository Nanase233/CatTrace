# 📱 手机访问指南

## 功能概述

项目猫-MVP 现已支持手机拍照识别猫咪功能！您可以：
- 📸 使用手机摄像头直接拍照
- 🖼️ 从相册选择已有照片
- 🔍 实时识别照片中的猫咪身份
- ➕ 注册新猫咪到识别数据库

---

## 🚀 快速开始

### 步骤 1：获取电脑 IP 地址

**Windows 系统：**
```cmd
ipconfig
```
找到 "无线局域网适配器 WLAN" 下的 "IPv4 地址"，例如：`192.168.1.100`

**macOS 系统：**
```bash
ifconfig
```
或进入 "系统偏好设置" → "网络" 查看 IP 地址

---

### 步骤 2：确保手机和电脑在同一 WiFi 网络

手机和电脑必须连接到**同一个 WiFi 网络**才能访问。

---

### 步骤 3：在手机上访问

打开手机浏览器，输入：
```
http://你的电脑 IP:5000/mobile
```

例如：
```
http://192.168.1.100:5000/mobile
```

---

## 📋 使用流程

### 1. 拍照识别
```
打开页面 → 授权摄像头 → 对准猫咪拍照 → 点击"开始识别" → 查看结果
```

### 2. 相册选择
```
打开页面 → 点击"从相册选择" → 选择猫咪照片 → 点击"开始识别" → 查看结果
```

### 3. 注册新猫咪
```
识别未知猫咪 → 点击"注册新猫咪" → 输入猫咪名称和 ID → 注册成功
```

## 🎯 功能说明

### 拍照功能
- 自动调用手机后置摄像头
- 实时预览拍摄画面
- 支持重拍功能

### 相册选择
- 支持从手机相册选择照片
- 自动识别图片格式
- 支持所有常见图片格式

### 识别结果
- **已识别猫咪**：显示猫咪名称、ID、置信度
- **未知猫咪**：显示相似度，可注册为新猫咪

### 注册功能
- 识别未知猫咪后可直接注册
- 输入猫咪名称和 ID
- 注册后立即加入识别数据库

## ⚙️ 常见问题

### Q1: 无法访问页面？
**检查项：**
- 确认电脑 IP 地址正确
- 确认手机和电脑在同一 WiFi 网络
- 确认服务器正在运行（app_mvp.py）
- 检查防火墙是否阻止了 5000 端口

### Q2: 摄像头无法打开？
**解决方法：**
- 检查是否授权浏览器访问摄像头
- 尝试使用 Chrome 或 Safari 浏览器
- 确保使用 HTTPS（局域网 HTTP 通常可用）

### Q3: 识别不准确？
**优化建议：**
- 确保猫咪脸部清晰可见
- 光线充足，避免逆光
- 拍摄猫咪正面照片
- 增加注册照片数量（建议 5 张以上）

### Q4: 页面显示不正常？
**解决方法：**
- 使用现代浏览器（Chrome、Safari、Edge）
- 清除浏览器缓存
- 确保手机浏览器支持 HTML5

## 🔐 安全提示

1. **局域网访问**：当前仅支持局域网访问，不要将服务暴露在公网
2. **权限管理**：首次访问需要授权摄像头权限
3. **数据隐私**：照片仅用于识别，不会永久保存
