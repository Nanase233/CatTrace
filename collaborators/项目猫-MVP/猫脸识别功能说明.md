# 猫脸识别功能说明

## 📋 功能概述

项目猫-MVP 现已支持基于深度学习的猫脸识别功能，可以：

1. **自动识别**：自动识别上传照片中的猫咪身份
2. **猫咪注册**：通过多张照片注册新猫咪
3. **相似度匹配**：使用余弦相似度算法进行特征匹配

---

## 🏗️ 技术架构

### 模型选择
- **特征提取器**: MobileNetV2 (预训练于 ImageNet)
- **相似度计算**: 余弦相似度 (Cosine Similarity)
- **猫检测**: OpenCV Haar Cascade 或简化模式

### 工作流程
```
照片上传 → 猫脸检测 → 特征提取 → 数据库匹配 → 返回识别结果
```

## 🔧 API 接口

### 1. 识别照片中的猫咪

**接口**: `POST /api/recognize`

**请求**:
```bash
curl -X POST http://localhost:5000/api/recognize \
  -F "photo=@cat_photo.jpg"
```

**响应**:
```json
{
  "success": true,
  "recognition": {
    "matched": true,
    "cat_id": 1,
    "cat_name": "咪咪",
    "confidence": 0.85,
    "cats_detected": 1
  }
}
```

---

### 2. 识别已上传的照片

**接口**: `GET /api/recognize-photo/<filename>`

**示例**:
```bash
curl http://localhost:5000/api/recognize-photo/ESP32_001_20260610_103000.jpg
```

---

### 3. 注册新猫咪

**接口**: `POST /api/register-cat`

**请求**:
```bash
curl -X POST http://localhost:5000/api/register-cat \
  -F "cat_id=5" \
  -F "cat_name="大黄"" \
  -F "photos=@cat1.jpg" \
  -F "photos=@cat2.jpg" \
  -F "photos=@cat3.jpg"
```

**说明**: 
- `cat_id`: 猫咪的唯一标识
- `cat_name`: 猫咪名称
- `photos`: 多张猫咪照片（建议 3-5 张不同角度）

**响应**:
```json
{
  "success": true,
  "message": "猫咪 大黄 注册成功",
  "image_count": 3
}
```

---

### 4. 获取已注册的猫咪列表

**接口**: `GET /api/registered-cats`

**响应**:
```json
[
  {
    "id": 1,
    "name": "咪咪",
    "image_count": 5,
    "registered_at": "2026-06-10T10:00:00"
  }
]
```

---

### 5. 自动识别上传（ESP32 专用）

**接口**: `POST /api/auto-recognize-upload`

**说明**: 结合照片上传和自动识别，ESP32 上传照片后自动进行识别

## 📁 数据存储

### 猫咪特征数据库
- **位置**: `models/cat_database.json`
- **格式**: JSON
- **内容**: 已注册猫咪的基本信息

### 猫咪特征向量
- **位置**: `models/cat_features.pkl`
- **格式**: Pickle
- **内容**: 每只猫咪的特征向量

### 上传的照片
- **位置**: `static/uploads/`
- **格式**: JPG/PNG

## 🎯 使用示例

### Python 客户端示例

```python
import requests

# 识别照片
response = requests.post(
    'http://localhost:5000/api/recognize',
    files={'photo': open('cat_photo.jpg', 'rb')}
)
result = response.json()

if result['success']:
    recognition = result['recognition']
    if recognition['matched']:
        print(f"识别到猫咪：{recognition['cat_name']}")
        print(f"置信度：{recognition['confidence']:.2%}")
    else:
        print("未识别到已知猫咪")
```

### 注册猫咪示例

```python
import requests

# 准备猫咪照片
photos = [
    ('photos', open('cat1.jpg', 'rb')),
    ('photos', open('cat2.jpg', 'rb')),
    ('photos', open('cat3.jpg', 'rb')),
]

# 注册
response = requests.post(
    'http://localhost:5000/api/register-cat',
    data={
        'cat_id': '5',
        'cat_name': '大黄'
    },
    files=photos
)

print(response.json())
```

### 识别阈值
在 `cat_face_recognition.py` 中可调整识别阈值：

```python
def recognize(self, image_path, threshold=0.6):
    # threshold: 0.5-0.8 之间
    # 越低越宽松，越高越严格
```

**建议值**:
- `0.5`: 宽松模式，容易匹配但可能误识别
- `0.6`: 标准模式，平衡准确率和召回率
- `0.8`: 严格模式，准确率高但可能漏识别

## 🐛 故障排查

### 问题 1: 猫脸识别模块未启用

**原因**: 依赖未安装

**解决**:
```bash
pip install tensorflow opencv-python scikit-learn
```

### 问题 2: 识别准确率不高

**原因**: 
- 注册照片太少
- 照片质量差
- 阈值设置过高

**解决**:
- 增加注册照片数量（建议 5 张以上）
- 使用不同角度、光照条件的照片
- 适当降低识别阈值

### 问题 3: 模型加载失败

**原因**: TensorFlow 版本不兼容

**解决**:
```bash
pip install tensorflow>=2.10.0
```

## 📊 准确率说明

| 场景 | 准确率 | 说明 |
|------|--------|------|
| 清晰正面照 | 90%+ | 最佳识别条件 |
| 侧面/倾斜 | 75-85% | 可接受范围 |
| 光线昏暗 | 60-75% | 可能误识别 |
| 多只猫同框 | 70-80% | 识别第一只 |

## 🔐 安全建议

1. **限制上传频率**: 防止滥用
2. **验证文件类型**: 只允许图片格式
3. **大小限制**: 限制单张图片大小
4. **定期清理**: 清理临时文件和旧照片
