# CatTrace 自学习引擎技术文档

> 自学习引擎（`self_learning.py`）是贯穿三大核心功能的 AI 能力层。

---

## 设计理念

平台越用越聪明——通过收集用户行为和猫咪数据，自动学习模式、发现异常、优化体验。

**纯 Python 标准库实现**，零外部 ML 依赖。

## 四大学习能力

### 能力一：🐱 猫咪行为模式学习

| 学习维度 | 数据来源 | 学习结果示例 |
|---------|---------|------------|
| 活跃时段 | 投喂时间分布 | "咪咪最喜欢中午 12 点来吃饭" |
| 进食频率 | 投喂次数统计 | "大橘每天平均被投喂 4.2 次" |
| 情绪规律 | 日记情绪标签 | "小黑夜间偏警惕，白天较放松" |
| 社交关联 | 同时投喂记录 | "咪咪和小黑常被同一人投喂" |

### 能力二：👤 用户偏好学习

| 行为信号 | 学到的偏好 |
|---------|----------|
| 经常投喂某只猫 | "小明最喜欢咪咪" |
| 频繁查看某区域 | "小红关注 A 区的猫咪" |
| 经常在晚上投喂 | "小明是夜猫子用户" |
| 日记互动多 | "小红是高参与度用户" |

### 能力三：🔍 异常检测与健康预警

| 异常类型 | 检测方式 | 预警内容 |
|---------|---------|---------|
| 突然消失 | 某猫连续 3 天无投喂 | "大橘 3 天没出现了" |
| 进食异常 | 单日投喂超均值 2 倍 | "雪球今天被喂了 12 次，注意过食" |
| 情绪变化 | 连续 3 天情绪低落 | "小黑情绪偏低，建议关注" |
| 用户异常 | 短时间大量投喂 | "检测到异常投喂行为" |

**健康评分公式**：
```
健康分 = 基础分(70) + 进食规律分(0~15) + 情绪稳定分(0~10)
       + 活跃趋势分(0~5) - 异常扣分(0~30)
```

### 能力四：📈 识别自优化

```
系统识别为"咪咪"(置信度 0.7)
       ↓
用户纠正："不对，这是雪球"
       ↓
记录纠错日志 → 更新特征权重 → 下次识别更准确
```

## API 接口

| 接口 | 方法 | 说明 |
|------|------|------|
| `/api/learning/cat-profile/<id>` | GET | 获取猫咪学习画像 |
| `/api/learning/user-profile/<user_id>` | GET | 获取用户偏好画像 |
| `/api/learning/recommendations/<user_id>` | GET | 获取个性化推荐 |
| `/api/learning/anomalies` | GET | 获取异常预警列表 |
| `/api/learning/insights` | GET | 获取全局模式洞察 |
| `/api/learning/health-report/<id>` | GET | 获取猫咪健康报告 |
| `/api/learning/feedback` | POST | 提交识别纠错反馈 |
| `/api/learning/train` | POST | 触发模型重新训练 |
