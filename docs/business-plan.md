# CatTrace 商业与技术计划

本文档整合 CatTrace 的市场分析、产品设计、技术方案和商业规划，作为项目唯一的商业计划文档。

---

## 1. 市场背景

### 1.1 行业数据

| 数据 | 说明 |
|------|------|
| 5000-8000 万只 | 中国流浪猫数量，且持续增长 |
| 3 亿+ | "云吸猫"用户，想看猫但养不了 |
| 2793 亿元 | 2024 年中国宠物经济规模 |

### 1.2 四方痛点

| 角色 | 困难 | CatTrace 的解法 |
|------|------|----------------|
| 爱心人士 | 想喂猫找不到，不知道钱花哪了 | 远程投喂 + 透明记录 |
| 物业/社区 | 猫扰民投诉多，左右为难 | 数据化治理工具 |
| 志愿者 | 找猫靠蹲、领养靠运气 | 智能定位 + 高效匹配 |
| 领养人 | 怕猫有病、怕"星期猫" | 真实档案 + 严选流程 |

### 1.3 核心思路

```
智能猫屋（硬件）  -->  数据采集（AI 识别）  -->  平台管理（软件）
      |                      |                      |
  投喂/直播            猫咪数字身份         投喂->绝育->领养->治理
```

---

## 2. 产品定位

**项目名称**：CatTrace -- 流浪猫科学救助平台
**项目性质**：课程实践项目
**当前版本**：MVP v3.0

CatTrace 在小区、校园、公园部署智能猫屋，让用户在手机上看到猫咪、远程投喂、申请领养，同时帮助物业和志愿者科学管理流浪猫。

## 4. 技术方案

### 4.1 技术栈

| 层级 | 技术 | 说明 |
|------|------|------|
| 后端 | Python 3.6+ / Flask | 轻量 REST API |
| 前端 | HTML5 + CSS3 + JS | 原生开发，零框架依赖 |
| 数据 | JSON 文件存储 | 原子写入保安全 |
| 自学习 | Python 内置算法 | 统计 + 模式识别 + 异常检测 |
| PWA | Service Worker | 离线可访问 |

### 4.2 硬件方案

#### 边缘节点（直播主力）

| 组件 | 选型 | 说明 |
|------|------|------|
| 主板 | 树莓派 4B / 香橙派 Orange Pi Zero 3 | 运行 Linux，负责摄像头推流与数据上报 |
| 摄像头 | USB 摄像头 / CSI 摄像头 | MJPEG 推流或快照轮询 |
| 环境传感器 | DHT22（温湿度）/ MQ-135（空气质量） | 通过 GPIO 采集 |
| 供电 | 太阳能板 + 锂电池 | 户外场景持续供电 |
| 网络 | WiFi / 4G 模块 | 上报数据至云端平台 |

#### 可选传感器扩展节点

| 组件 | 选型 | 说明 |
|------|------|------|
| 主板 | ESP32 | 低成本独立传感器节点 |
| 传感器 | 温湿度 / 光照 / 红外 | 通过 WiFi 上报至平台 |
| 定位 | 可选 GPS 模块 | 辅助猫屋选址与位置记录 |

ESP32 不作为直播推流设备，仅用于轻量传感器数据采集与上报。

### 4.3 数据流

```
用户浏览器                    Flask 后端                     数据存储
    |                            |                            |
    |  POST /api/feed            |                            |
    +--------------------------->|                            |
    |                            |  load_data()               |
    |                            +--------------------------->|
    |                            |<---------------------------+
    |                            |                            |
    |                            |  更新 feed_count           |
    |                            |  追加 feed_log             |
    |                            |  触发自学习引擎            |
    |                            |  save_data()               |
    |                            +--------------------------->|
    |  {"success": true}         |                            |
    |<---------------------------+                            |
```
