# CatTrace 项目路线图与远期规划

---

## 实施路线

| 阶段 | 时间 | 目标 | 核心指标 |
|------|------|------|---------|
| **MVP（当前）** | 0-6 月 | Web 端全流程跑通 | 4 猫建档、投喂/举报/领养可用 |
| **硬件接入** | 6-12 月 | 树莓派/香橙派摄像头接入 | 1-3 台边缘节点上线 |
| **试点运营** | 12-24 月 | 3-5 台猫屋实地部署 | 识别率≥85%、7日留存≥30% |
| **规模化** | 24-36 月 | 10+ 点位、小程序上线 | 日活 1000+、付费转化 5% |

## 自学习模块演进

| 版本 | 能力 | 技术依赖 |
|------|------|---------|
| v1.0 | 统计分析 + 规则引擎 + 异常检测 | Python 标准库 |
| v2.0 | 机器学习聚类/分类 | scikit-learn |
| v3.0 | 深度学习猫脸识别 | TensorFlow + YOLOv8 |
| v4.0 | LLM 智能日记 + 对话助手 | OpenAI API |

详见 [self-learning.md](./self-learning.md)。

## 下一步优先事项

1. 🔧 **组装硬件原型**：树莓派/香橙派 + 摄像头 + 环境传感器
2. ⭐ **完善自学习模块**：积累真实数据，验证异常检测算法
3. 📱 **开发小程序版**：降低用户使用门槛
4. 🏘️ **寻找试点场地**：联系 1-2 个合作物业/校园
