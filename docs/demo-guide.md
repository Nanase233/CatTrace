# 离线版网页使用说明

CatTrace 提供两种「双击即开」的静态页面，用途不同，别拿错：

| 文件 | 是什么 | 是否最新界面 |
|------|--------|--------------|
| `index.html` / `live.html` / `cats.html` / `adopt.html` | **最新网页的离线版**，由 `templates/` + `static/` 导出，内置接口数据快照 | ✅ 是 |
| `demo.html` | 9 月最早的产品原型静态页 | ❌ 否，仅作历史对照 |

---

## 一、离线版网页（推荐）

### 启动方式

直接双击仓库根目录的 `index.html`，或把文件拖进浏览器窗口。
页面之间通过顶部导航互相跳转，无需 Python、无需后端服务、无需联网。

### 包含哪些页面

| 文件 | 对应线上路由 | 内容 |
|------|--------------|------|
| `index.html` | `/` | 首页：Hero、猫屋地图、实时云直播预览、AI 日记、猫咪档案、领养进度、人气榜 |
| `live.html` | `/live` | 云直播：播放器、实时互动、远程投喂、AI 识别动态 |
| `cats.html` | `/cats` | 猫咪档案：搜索、状态筛选、点击卡片查看详情 |
| `adopt.html` | `/adopt` | 领养中心：可领养猫咪、领养流程、申请表单 |

### 数据是怎么来的

导出脚本会先启动 Flask 测试客户端，把 `/api/cats`、`/api/stats`、`/api/diaries` 等接口
的真实返回抓成快照，写进 `static/js/offline-mock.js`。这个脚本在页面脚本之前劫持
`window.fetch`，所以页面拿到的数据和自己跑 Flask 时一样。

投喂、领养申请之类会改数据的操作，离线版只返回一条成功提示，不会真的写入。

### 网页更新后如何重新导出

```bash
python scripts/build_offline_site.py
```

需要 `Flask>=2.0`（见 `requirements.txt`）。脚本会覆盖根目录的 4 个 HTML，并重写
`static/js/offline-mock.js`，其余文件不动。

> 注意：`/diary`（旧版日记页）没有导出。新首页已经内置 AI 日记模块，`templates/diary.html`
> 是改版前的页面，样式和脚本都对不上，等负责人重做后再加进导出列表。

## 二、demo.html（旧版原型，仅作对照）

`demo.html` 是项目最早的产品原型页，界面上还是改版前的样式，只保留下来做历史对照。

| 场景 | 说明 |
|------|------|
| 历史对照 | 想看看改版前后的差别 |
| 课堂演示 | 双击即可打开，不依赖任何外部环境 |

### 与 Flask 完整版的区别

| 对比项 | demo.html / 离线版 | Flask 完整版 |
|--------|--------------------|--------------|
| 启动方式 | 双击打开 | `python app.py` |
| 后端依赖 | 无 | Flask + Python 3.10+ |
| 数据来源 | 打包好的 JSON 快照 | `data.json` 实时读写 |
| 写操作 | 只给提示，不持久化 | 真正写入 |
| 自学习引擎 | 无 | `self_learning.py` |
| 用户认证 | 无 | 手机号 + 验证码 |
| PWA 支持 | 仅线上（Service Worker 需要 http） | 有 |

如需完整功能体验，请用 Flask 完整版（见 [README.md](../README.md) 的「如何体验项目」）。
