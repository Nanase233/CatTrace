# demo.html 使用说明

demo.html 是 CatTrace 的独立静态演示页，无需后端服务器、无需 Python、无需网络连接。

---

## 使用场景

| 场景 | 说明 |
|------|------|
| 课堂演示 | 双击即可打开，不依赖任何外部环境 |
| 离线展示 | 适合无网络环境的汇报和答辩 |
| 快速预览 | 无需安装依赖即可查看界面效果 |

## 启动方式

直接双击 `demo.html` 文件，或拖入任意浏览器窗口。

## 功能范围

demo.html 包含以下模拟内容：

| 模块 | 说明 | 数据来源 |
|------|------|---------|
| 实时直播界面 | 模拟猫咪直播画面（动画） | 前端内置 |
| 环境监测数据 | 温度、湿度模拟值 | 前端随机生成 |
| 猫咪档案卡片 | 4 只示例猫咪信息 | 前端内置 |
| 投喂交互 | 模拟投喂按钮与计数 | 前端状态，不持久化 |
| 猫咪日记 | 示例日记条目 | 前端内置 |

## 与 Flask 完整版的区别

| 对比项 | demo.html | Flask 完整版 |
|--------|-----------|-------------|
| 启动方式 | 双击打开 | `python app.py` |
| 后端依赖 | 无 | Flask + Python 3.6+ |
| 数据持久化 | 无（刷新丢失） | JSON 文件存储 |
| 自学习引擎 | 无 | self_learning.py |
| 用户认证 | 无 | 手机号 + 验证码 |
| API 接口 | 无 | 完整 REST API |
| PWA 支持 | 无 | Service Worker |

如需完整功能体验，请使用 Flask 完整版（见 README.md 快速开始）。
