# CatTrace 系统架构与硬件方案

---

## 技术栈

| 层级 | 技术 | 说明 |
|------|------|------|
| **后端** | Python 3.6+ / Flask | 轻量 REST API |
| **前端** | HTML5 + CSS3 + JS | 原生开发，零框架依赖 |
| **数据** | JSON 文件存储 | 原子写入保安全 |
| **自学习** | Python 内置算法 | 统计 + 模式识别 + 异常检测 |
| **PWA** | Service Worker | 离线可访问 |

## 硬件方案

### 边缘节点（直播主力）

| 组件 | 选型 | 说明 |
|------|------|------|
| 主板 | **树莓派 4B** / **香橙派 Orange Pi Zero 3** | 运行 Linux，负责摄像头推流与数据上报 |
| 摄像头 | USB 摄像头 / CSI 摄像头 | MJPEG 推流或快照轮询 |
| 环境传感器 | DHT22（温湿度）/ MQ-135（空气质量） | 通过 GPIO 采集 |
| 供电 | 太阳能板 + 锂电池 | 户外场景持续供电 |
| 网络 | WiFi / 4G 模块 | 上报数据至云端平台 |

### 可选传感器扩展节点

| 组件 | 选型 | 说明 |
|------|------|------|
| 主板 | ESP32 | 低成本独立传感器节点 |
| 传感器 | 温湿度 / 光照 / 红外 | 通过 WiFi 上报至平台 |
| 定位 | 可选 GPS 模块 | 辅助猫屋选址与位置记录 |

> ESP32 不作为直播推流设备，仅用于轻量传感器数据采集与上报。

## 数据流

```
用户浏览器                    Flask 后端                     数据存储
    │                            │                            │
    │  POST /api/feed            │                            │
    ├───────────────────────────→│                            │
    │                            │  load_data()               │
    │                            ├───────────────────────────→│
    │                            │←───────────────────────────┤
    │                            │                            │
    │                            │  更新 feed_count           │
    │                            │  追加 feed_log             │
    │                            │  触发自学习引擎            │
    │                            │  learning_engine.update()  │
    │                            │  save_data()               │
    │                            ├───────────────────────────→│
    │  {"success": true}         │                            │
    │←───────────────────────────┤                            │
```

### 硬件数据流（规划中）

```
树莓派/香橙派                 Flask 后端                    用户浏览器
    │                            │                            │
    │  摄像头 MJPEG 推流          │                            │
    ├───────────────────────────→│                            │
    │                            │  转发视频流                │
    │                            ├───────────────────────────→│
    │  环境传感器数据 (JSON)      │                            │
    ├───────────────────────────→│                            │
    │                            │  存储 + 触发异常检测       │
    │                            │  展示在直播页面            │
    │                            ├───────────────────────────→│
```
