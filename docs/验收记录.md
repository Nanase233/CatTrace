### ⚠️ 已知硬件问题：供电不足

```
$ vcgencmd get_throttled
throttled=0x50005
```

`0x50005` = 曾发生欠压 + 当前仍欠压 + 已触发节流。**必须换 5V/3A 电源**，否则高负载（跑模型）时会掉帧甚至重启。

## 三、实测性能（Pi4，1GB，Mock 模型）

| 环节 | 实测 |
|---|---|
| 合成源 → 落盘 | 3.0 fps（限速下） |
| CSI 640x480 采集 | measured 3.0 fps / effective 3.16 fps |
| CSI 全链路（Mock 模型） | 10 帧 9.07s（含 1s 预热） |
| 合成 60 帧全链路 | 20.13s（约 3 fps） |
| 单帧落盘占用 | 约 200KB；30 帧 ≈ 0.57MB |
| `/dev/shm` 总量 | 453MB |
| 可用内存（未跑 AI） | 约 667MB |

**预算提示**：AI 抽帧固定 2~3fps。猫脸、耳标模块的模型必须让"单帧推理"控制在 ~300ms 以内，
否则 1GB 内存 + 单核推理会成为瓶颈。

## 四、下一步（按优先级）

1. **换 5V/3A 电源**（否则后面跑模型必崩）。
2. 猫脸、耳标模块在 `modules/catface/`、`modules/earnotch/` 里按 `contracts/` 实现真模型，
   先用 `file:` / `synthetic:` 回放源开发，不用等摄像头。
3. 猫脸、耳标模块上线后跑同样三条命令（S1/S2/S3）做联调回归 —— 验收标准不变。
4. 可选：`sudo systemctl set-default multi-user.target` 关掉桌面，释放约 269MB 内存，开机 3min → 30s。
