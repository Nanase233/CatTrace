## 一、三大核心功能

### 1.1 📹 实时直播与在线巡检 `P0 · 🔧 MVP 模拟`

**做什么**：在小区、校园、公园的智能猫屋部署摄像头，让用户和志愿者可以远程实时查看猫咪状态。

**硬件方案**：

| 组件 | 选型 | 说明 |
|------|------|------|
| 边缘节点 | 树莓派 4B / 香橙派 Orange Pi Zero 3 | 运行 Linux，接入摄像头与环境传感器 |
| 摄像头 | USB 摄像头 / CSI 摄像头 | MJPEG 推流或快照轮询 |
| 环境传感器 | DHT22（温湿度）/ MQ-135（空气质量） | 通过 GPIO 采集，上报至平台 |
| 供电 | 太阳能板 + 锂电池 | 户外场景持续供电 |
| 可选扩展 | ESP32 传感器节点 | 独立部署，通过 WiFi 上报温湿度等数据 |

**MVP 当前状态**：Web 页面已实现模拟直播界面（含猫咪动画、环境监测数据模拟），实际硬件接入待开发。

**在线巡检**：志愿者可通过直播画面远程巡查猫咪健康状况，发现异常及时处理。

### 1.2 🍖 远程投喂与投喂追溯 `P0 · ✅ 已完成`

**做什么**：用户点击"投喂"按钮，系统记录完整的投喂链路。

**操作流程**：
```
用户选择猫咪 → 填写昵称 → 点击投喂 → 投喂次数 +1 → 生成投喂日志 → 自学习引擎更新
```

**安全限制**：

| 用户类型 | 投喂限制 | 说明 |
|---------|---------|------|
| 游客 | 最多 1 次 | 防止刷数据 |
| 登录用户 | 无限制 | 支持无限投喂 |

**投喂记录字段**：时间戳、猫咪 ID、用户昵称、投喂包类型、是否登录。

**自学习赋能**：
- 投喂规律学习：自动统计每只猫的日均投喂次数、高峰时段
- 异常投喂提醒：单日投喂超均值 2 倍时预警
- 阈值自校准：根据历史数据自动调整告警阈值

### 1.3 📋 AI 猫咪档案 `P0 · ✅ 已完成`

**做什么**：为每只建档的流浪猫创建完整的"数字身份证"。

**每只猫包含的信息**：

| 字段 | 说明 | 示例 |
|------|------|------|
| name | 名字 | 咪咪 |
| nickname | 昵称 | 小区一霸 |
| gender | 性别 | female / male |
| age | 年龄 | 2 岁 |
| color | 毛色 | 橘白相间 |
| location | 位置 | A 区 - 教学楼后 |
| health | 健康状态 | 健康 / 需关注 |
| neutered | 是否绝育 | true / false |
| adoption_ready | 是否可领养 | true / false |
| feed_count | 累计投喂次数 | 156 |

**当前 4 只示例猫咪**：

| 猫咪 | 昵称 | 性格 | 位置 | 特点 |
|------|------|------|------|------|
| 🐱 咪咪 | 小区一霸 | 活泼，爱晒太阳 | A 区 | 已绝育，暂不可领养 |
| 🐈‍⬛ 小黑 | 夜行侠 | 夜间活跃，警惕 | B 区 | 未绝育，可领养 |
| 🤍 雪球 | 棉花糖 | 非常亲人 | C 区 | 已绝育，可领养 |
| 🧡 大橘 | 十斤橘 | 慵懒贪吃 | D 区 | 体重超标需关注 |

**自学习赋能**：
- 健康评分：基于进食规律、情绪稳定性、活跃趋势自动计算健康分（0-100）
- 猫脸识别辅助建档：📋 规划中（MobileNetV2 + 余弦相似度）

## 二、辅助功能

### 2.1 用户认证 `P0 · ✅ 已完成`

手机号 + 验证码登录（MVP 阶段验证码固定为 `8888`）。

| 功能 | 游客 | 正式用户 | 认证志愿者 |
|------|------|---------|-----------|
| 浏览猫咪 | ✅ | ✅ | ✅ |
| 投喂 | 1 次 | 无限 | 无限 |
| 申请领养 | ❌ | ✅ | ✅ |
| 举报 | ❌ | ✅ | ✅ |
| 查看精确位置 | ❌ | ❌ | ✅ |

### 2.2 猫咪日记 `P1 · ✅ 已完成`

系统为每只猫自动生成每日"微观日记"，记录来访次数、停留时长、情绪状态。支持用户点赞和评论互动。

### 2.3 领养申请 `P1 · ✅ 已完成`

在线提交领养申请，系统自动验证年龄、必填项完整性、目标猫咪状态（健康 + 已绝育 + 可领养）。

### 2.4 举报与紧急求助 `P1 · ✅ 已完成`

| 类型 | 触发方式 | 系统响应 |
|------|---------|---------|
| 普通举报 | 选择类型 + 描述 | 记录存档，等待处理 |
| 紧急举报 | 勾选"紧急" | 自动生成求助卡片，向所有用户广播 |

举报类型：受伤、被虐待、受困、生病、失踪、其他。

### 2.5 位置脱敏 `P1 · ✅ 已完成`

| 用户等级 | 看到的位置 | 示例 |
|---------|----------|------|
| 普通用户 | 仅区域 | "A 区" |
| 认证志愿者 | 精确位置 | "A 区 - 教学楼后" |
| 紧急模式 | 完整位置 | 含坐标信息 |

### 2.6 财务透明看板 `P1 · ✅ 已完成`

收支分类统计 + 月度趋势图 + 交易记录筛选。做到"每一分钱都看得见"。

### 2.7 志愿者管理 `P2 · ✅ 已完成`

申请 / 审核 / 积分体系。志愿者可查看精确位置、处理紧急求助。

### 2.8 通知系统 `P2 · ✅ 已完成`

投喂通知 + 紧急求助推送。
