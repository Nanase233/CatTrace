# 接手流程：拉取代码、装软件、分工怎么走

> 面向：猫脸识别 / 剪耳识别 / 摄像头联调 三位成员。
> 目标：每个人单独一条命令就能把链路跑起来，改完只在 `dev` 上对，主分支不动。

## 一、你要装什么软件（按角色，按需）

### 所有成员都要（Windows 或树莓派都一样）

| 软件 | 版本 | 装法 | 为什么 |
|------|------|------|--------|
| **Git** | ≥ 2.30 | `winget install Git.Git` / `sudo apt install git` | 拉代码、提 PR |
| **Python** | ≥ 3.10（Pi 上是 3.13，本机建议 3.11/3.13） | [python.org](https://www.python.org/downloads/) / `sudo apt install python3-venv` | 跑流水线 |
| **pip + venv** | 随 Python | `python -m ensurepip` | 隔离依赖 |
| **jsonschema / pytest / ruff** | 见下 | `pip install -e ".[dev]"` | 契约测试 + 单测 + 静态检查 |

> 只装开发依赖就能跑 L1~L4 五层验证里的四层。**没有摄像头也能开发**，用 `synthetic:` 合成源或 `file:` 回放源。

### 按角色额外装

| 角色 | 额外软件 | 装法 |
|------|----------|------|
| **摄像头与联调** | picamera2（CSI 驱动）、ffmpeg、sqlite3 | 树莓派：`sudo apt install -y python3-picamera2 ffmpeg sqlite3`；或直接跑 `bash scripts/setup_pi.sh` |
| **猫脸识别** | numpy、opencv-python-headless、onnxruntime（+ 训练端：PyTorch 或 MMDetection） | `pip install numpy opencv-python-headless onnxruntime`；训练端按模型文档单独装 |
| **剪耳识别** | 同猫脸（共享推理栈） | 同上 |
| **前端/后端对接** | Flask（网页端）、requests | `pip install flask requests` |

**树莓派 4（1GB）特别注意**：内存只有 ~900MB，Power 必须用 **5V/3A** 供电，
否则 `vcgencmd get_throttled` 报错会拖慢甚至卡死。摄像头与联调负责人已在
`scripts/setup_pi.sh` 里关掉图形桌面省内存。

## 二、拉代码（每人第一步，照抄）

```bash
# 1. 克隆团队仓库（公开仓库，无需权限即可读）
git clone https://github.com/chenglian07/TNR.git
cd TNR

# 2. 建自己的虚拟环境（Pi 上必须加 --system-site-packages，否则看不到 picamera2）
python3 -m venv --system-site-packages .venv
source .venv/bin/activate            # Windows: .venv\Scripts\activate

# 3. 装开发依赖
pip install -e ".[dev]"

# 4. 自证：摄像头接入 + 模块联调是否真的通
python scripts/verify_catvision.py
```

看到 `全部通过：摄像头接入 + 模块联调 已实际打通。` 就算环境 OK。
（没有摄像头的电脑 L5 会 `[SKIP]`，属正常。）

## 三、分工与目录边界（各写各的，别越界）

| 角色 | 只改这些目录 | 输入 → 输出 |
|------|--------------|-------------|
| **摄像头与联调** | `modules/camera/`、`pipeline/`、`scripts/` | 摄像头 → `FramePacket`，并负责抽帧/事件总线/决策/部署 |
| **猫脸识别** | `modules/catface/` | `FramePacket` → `list[CatFace]` |
| **剪耳识别** | `modules/earnotch/` | `FramePacket` + `list[CatFace]` → `list[EarNotch]` |

**三个铁律**（见 README-catvision.md）：

1. 跨模块**只通过 `contracts/`** 交互，禁止 import 别人模块内部代码。
2. 改 `contracts/` 必须走 PR 且另外两个模块 approve。
3. 每人必须交 Mock，没有 Mock 就没有并行。

## 四、Git 流程（每人都一样）

```bash
git checkout dev
git pull origin dev

git checkout -b feat/catface-xxx        # 分支名：feat/<模块>-<说明>
# ...改代码...
git add -A
git commit -m "feat(catface): 加个体ID投票"
git push origin feat/catface-xxx
```

然后在 GitHub 上发 **Pull Request：你的分支 → `dev`**，等 CI 绿 + 另外两人 approve 再合。
**不要直接推 `main`。**

## 五、提交前的必做动作

```bash
# 1. 单测 + 契约测试
pytest -q

# 2. 全链路自证（含真帧回放与契约联调）
python scripts/verify_catvision.py

# 3. 静态检查（CI 会卡这一条）
ruff check .
```

三条全过再提 PR，CI 基本一次绿。

## 六、只有你能做的两件事

| 事项 | 谁做 | 说明 |
|------|------|------|
| 在树莓派上加**只读 deploy key** | 摄像头与联调 | Pi 部署用；老仓库的 key 对新仓库无效，需要新加一把 |
| 提交真实 CSI 摄像头验收记录 | 摄像头与联调 | L5 只能在插着摄像头的树莓派上跑 |

其余成员在**没有摄像头**的笔记本上就能完成各自模块的开发与自测
（用 `--source synthetic:` 或 `--source file:datasets/...`）。
